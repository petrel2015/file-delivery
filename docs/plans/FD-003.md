# FD-003 本地账本和模拟存储

前置：FD-002须先验收并发布。CLI deliver-local复用planner与archive，创建SQLite任务账本；status读取持久状态。只支持本机可信单用户，不涉及远端对象、公开链接或发送渠道。

用户指定state-dir为本地密码恢复边界：0700目录，数据库/锁/对象文件0600，密码仅保留在既有bundle/password.txt；数据库只记录任务和非秘密路径/摘要。JSON只返回密码文件位置。主机同用户和管理员仍能读取秘密，跨设备托管与系统钥匙串不在本阶段。

幂等键对应规范化root+内容manifest+store位置，相同输入复用任务/归档/密码；不同内容或store报冲突。pending→packaged→stored-local状态分段持久化；每次重复请求读回本地对象hash，缺失可从原包恢复，损坏不得覆盖。进程级有界锁确保同key并发串行，进程退出后可重试。

控制器在after_pack和after_store两个持久产物边界分别注入OSError及os._exit，验证原密码和task_id恢复。单测覆盖同key并发、冲突、缺失/损坏对象、目录权限、日志无秘密和无网络。state/store必须彼此分离且在输入root之外。

最多初次+一次定点修复，各600秒，low8192；全部历史功能与补充修复成本合并统计。此处stored-local只说明本地模拟对象经hash读回，不代表真实上传或送达。
