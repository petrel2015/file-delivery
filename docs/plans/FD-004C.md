# FD-004C 撤销与到期清理

以已接受的FD-004B为基础，合同见contracts/FD-004C.json；Worker仅修改合同列出的七个文件，控制器测试保留此前所有合同与审查回归。

新交付记录持久化存储身份及保留策略，保留期从首次上传intent开始，不能在打包开始时提前计时。旧B记录没有这些元数据，必须拒绝删除，不能根据当前配置猜测所属空间。新要求属于C范围，不追溯为B验收失败。

revoke-qiniu只撤销账本自有对象；先记录revoking，再执行删除并查询确认。结果不确定时停止，下一次显式调用先查远端。revoking或已删除任务的同key交付不能重新上传复活，需明确新key。保留本地包、密码和handoff。

对象删除与原签名URL可用性独立报告。使用原链接进行无凭据的有限GET探测，不下载正文、不重定向、不签新链接；即使链接已到期也不因此阻止撤销。缓存仍可访问时必须明确link-accessible，不声称召回已下载副本。

cleanup-qiniu默认只读预览，--execute才执行。只处理账本中保留期已到、配置身份匹配的对象；链接到期本身不触发删除。单项失败保留具体安全错误并继续其他合格任务，未知删除不立即重试，不扫描整个bucket。

使用已授权的当前ZCode Coding Plan，多次修复策略沿用；连续无验证进展或未知执行先诊断，历史不清零。真实七牛配置仍待提供，Worker与控制器固定suite均只用合成数据。真实服务验收随后独立执行。
