## FD-004A 手递上下文

生产传输使用 requests.Session.request；控制器注入同接口的合成响应，禁止真实账户访问。签名采用七牛 SDK，qiniu 依赖是可选 extra，保持基础安装和 FD-001～003 行为。默认 7 天链接与 30 天保留期是独立策略；生命周期删除由服务异步处理，不能承诺精确秒级删除。表单上传足以验证首个存储闭环；当前未验证大文件性能和断点续传。

上传使用 insertOnly，按地域 HTTPS 域名发送，管理请求签名。禁止重定向与隐式重试；网络异常/5xx 作为 REMOTE_UNKNOWN，后续账本根据 stat 和下载核对决定如何恢复，不能把异常当成对象不存在。私有配置仅在用户本机，密码、签名链接及原始请求不得提交公共仓库。

Worker 使用现有 ZCode Coding Plan、GLM-5.3。每项初始调用加最多一次普通修复，独立审查至多两轮；本项使用交互式 idle watchdog 300 秒、无 wall deadline、验收 300 秒，不设置输出 token 上限。low 配置必须通过当前安装二进制的无上游 loopback 探针。派发使用私有 delivery-policy；费用未知保持 null。普通失败只反馈具体缺陷；超出限次由 Codex 判断，不开新 run 清零。
